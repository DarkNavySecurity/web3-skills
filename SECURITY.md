# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this repository — such as credentials in committed files, prompt injection vectors in skill prompts, or other risks — please report it privately.

**Email:** vr@darknavy.com

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

Do not open a public issue for security vulnerabilities.

## Scope

This repository contains skill prompts and reference files, not deployed services. Security concerns here typically involve:

- Credentials, API keys, or wallet addresses accidentally committed
- Prompt injection or jailbreak vectors in skill instructions
- Skill outputs that could mislead users into unsafe actions (e.g., approving malicious contracts)

## Response

We will acknowledge reports within 3 business days and provide a resolution timeline within 10 business days.
